# rotation-generator

고정 명단(소현/은영/제이/승미)과 4개 구역(화장실/주방/공용공간/분리수거)을
"한 명씩 아래로 내려가고 맨 아래가 맨 위로" 규칙에 따라 순환시켜 이번 주 매핑을
계산한다. 순수 계산 스크립트이며 판단이 필요한 부분은 없다.

## 언제 사용하는가
- 운영자가 매주 월요일 당번표 생성을 요청할 때
- 거주자가 그 주 결원(여행/병가 등)을 미리 알릴 때

## 사용법

```bash
python3 scripts/rotation.py run
```

- 같은 ISO 주차에 이미 실행된 적이 있으면 재계산하지 않고 기존 결과를 그대로 보여준다
  (중복 실행으로 로테이션이 밀리는 사고 방지).
- 구역 재배정 방식의 페널티는 더 이상 없다 (디파짓 차감 방식으로 대체됨 —
  `checklist-tracker` 참조). 이 스크립트는 순수하게 순환 계산과 결원 처리만 한다.
- `output/state.json`의 `zones` 배열 순서가 실제 순환 순서다. 표시 순서(공지문에
  보이는 순서)와 다를 수 있으니 절대 임의로 재정렬하지 말 것 — 실제 거주자들이
  써오던 순서와 어긋나면 당번표가 틀어진다.

결원 신고:

```bash
python3 scripts/rotation.py report-vacancy <이름>
```

이번 주 로테이션 계산 전에 실행해야 반영된다. 결원자의 구역은 이번 주 스킵되고,
다음 순번자가 2주 연속 담당하도록 자동 기록된다.

## 실행 순서 (매주 월요일)

전체 흐름에서 이 스킬은 다음 순서로 호출된다:

1. `checklist-tracker`의 `close-week` (지난주 마감 처리 — 연속 미제출 카운터와
   디파짓 차감을 먼저 갱신)
2. **`rotation-generator`의 `run`** (이 스킬)
3. `notice-formatter`의 `generate`

## 예외 상황 (에스컬레이션)

거주자 영구 교체(이사/신규 룸메이트), 명단 자체의 변경 요청은 이 스크립트가 처리하지
않는다. 정형화되지 않은 예외이므로 에이전트가 자연어로 상황을 파악하고, 필요하면
`output/state.json`의 `residents`/`zones`를 운영자와 함께 직접 수정하도록 안내한다.
