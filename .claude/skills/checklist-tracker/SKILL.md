# checklist-tracker

마감시각(자정 + 10분 유예) 경과분을 자동으로 '미제출' 처리하고, 운영자의 수동
완료 입력을 반영하며, 연속 미제출 카운터·디파짓 차감 장부·주차별 이력을 관리한다.

## 언제 사용하는가
- 매주 로테이션 계산 직전(지난주 마감 처리)
- 운영자가 "은영 완료 처리해줘" 같이 특정 인원의 완료를 알릴 때
  - **이름은 정확히 일치해야 한다.** 오타나 별명("은영이", "eunyoung" 등)이 들어오면
    자동으로 추측해서 처리하지 말고, 정확한 이름으로 다시 입력해달라고 요청한다
    (설계서 결정: 퍼지 매칭 없음, 확실성 우선).
- 거주자가 이력을 보고 싶다고 요청할 때 (요약만 공유 — 상시 셀프 조회 권한은 없음)
- 3개월 이상 지난 이력을 정리할 때

## 사용법

```bash
# 지난주 마감 처리 (매주 월요일, rotation-generator 실행 전)
python3 scripts/checklist.py close-week

# 완료 처리
python3 scripts/checklist.py complete 은영

# 최근 이력 요약 (기본 8주)
python3 scripts/checklist.py summary --weeks 8

# 3개월 이전 이력을 요약본으로 정리 (상세 삭제)
python3 scripts/checklist.py trim --months 3

# 디파짓 장부 / 공동 풀 현황 조회
python3 scripts/checklist.py deposit-status
```

## 사진 확인 원칙

당사자가 카카오톡 단체방에 "청소완료" 글과 사진을 올리면, 운영자는 평상시에는
사진을 정밀 검증하지 않고 그대로 신뢰하여 `complete`를 실행한다. 시스템은 사진을
저장하지 않는다. 이의제기(분쟁)가 발생했을 때만 운영자가 카카오톡 채팅방의 원본
게시물을 사후 확인한다 — 그게 유일한 근거 자료다.

## 연속 미제출 카운터 & 디파짓 페널티

- 마감을 놓치면 해당 인원의 연속 미제출 카운터가 +1 된다.
- 한 번이라도 제때 제출(`complete`)하면 카운터는 0으로 리셋된다.
- **1회차는 그냥 넘어간다 (차감 없음).** 2회차부터는 그 스트릭이 끊길 때까지
  매회 `close-week`가 자동으로 개인 디파짓 $10 차감 + 공동 풀 $10 적립을
  처리한다.
- 공동 풀이 $100에 도달하면 자동으로 회식비 사용 안내가 뜨고, 초과분만 남긴
  채 풀이 리셋된다.
- 이 차감 내역은 `state["deposit"]["pending_events"]`에 쌓였다가
  `notice-formatter`가 다음 공지문에 한 번 포함시키고 소비한다.
- 실제 돈을 걷고 보관하는 것은 운영자의 몫이다 — 이 스크립트는 장부만 관리한다.
- 구역을 재배정하는 페널티(공용공간 반반 분담)는 폐지되었다.
